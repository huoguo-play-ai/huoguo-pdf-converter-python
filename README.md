# PDF 转 Word（本地版）

把 PDF 转成**排版接近原文件、打开就能直接改**的 Word。全程在你自己的电脑上运行，文件不会上传到任何地方。

## 怎么用

1. 先装好 Python 3.10 或更新版本（https://www.python.org/downloads/ ）。Windows 安装时记得勾选「Add python.exe to PATH」。
2. Mac 双击 `开始转换.command`，Windows 双击 `开始转换.bat`。
   - 第一次运行会自动安装依赖，大约 1～3 分钟，之后再打开只要几秒。
   - Mac 如果提示「无法验证开发者」：右键点 `开始转换.command` →「打开」→ 再点「打开」。
3. 浏览器会自动打开工具页面。把 PDF 拖进去，点「开始转换」，转好后可以单个下载、打包下载，或者点「打开结果文件夹」。
4. 用完后关掉那个黑色的命令行窗口，工具就退出了。

不想开界面也可以批量转：把 PDF 放进一个文件夹，在命令行运行 `.venv/bin/python app.py --batch 文件夹路径`，结果和报告都在「转换结果」文件夹里。

## 它是怎么做到「排版接近、还能直接改」的

普通转换工具常用文本框把每段字「贴」到原来的位置，看着像，但一改就乱。这个工具反过来：先读出每个字的位置、字号、颜色，以及色块、分隔线、表格、图片，然后用 Word 自己的功能重新排一遍：

| PDF 里的东西 | 在 Word 里变成 |
| --- | --- |
| 一行行的文字 | 普通段落，用段前间距和固定行距对齐原来的位置 |
| 被自动换行切开的长段落 | 合并成一个段落（两端对齐），改字后会自动重新换行 |
| 左边标题、右边日期 | 同一段落里的制表位，日期始终靠右对齐 |
| 项目符号 | 悬挂缩进，换行后和文字对齐 |
| 标题左侧的色条 | 段落左边框 |
| 分隔线 | 段落下边框 |
| 带底色的提示框 | 段落底纹 + 边框 |
| 有框线的表格 | 真正的 Word 表格 |
| 照片等图片 | 按原位置浮动的图片，可以拖动 |
| 双栏排版 | Word 的分栏，文字会在两栏之间自动流动 |
| 每页底部的页脚 | Word 页脚，页码换成会自动更新的页码 |

## 做不到、或者做得不好的地方

- **扫描件**（整页都是图片）：没有文字识别（OCR），会直接跳过并提示。
- **字体**：中文统一换成电脑自带的字体（Mac 用苹方，Windows 用微软雅黑）。原 PDF 用的字体如果更细或更粗，看起来会有差别；字宽略有不同时，个别很长的行换行位置可能和原文不一样。
- **矢量画的图形**：图标、流程图、图表如果在 PDF 里是用线条画的（而不是图片），不会被转换，会丢失。
- **圆角、阴影、渐变**：带底色的框会变成直角，阴影和渐变会丢掉。
- **表格**：只识别有框线的表格；没有框线的表格按普通文字处理；合并单元格暂不支持。
- **复杂版式**：三栏及以上、文字环绕图片、竖排文字、页眉，目前都不支持或只按普通文字处理。
- **加密 PDF**：需要先解除密码。

## 怎么确认文件没有上传

- 工具只监听 `127.0.0.1`（就是你自己这台电脑），别的设备、别的网站都访问不到；其他网站发来的请求会被直接拒绝。
- 页面不加载任何外部网址的资源（字体、图标、脚本都在本地）。
- 最直接的办法：**断开网络（关掉 Wi-Fi）再转换一次**，照样能用。只有第一次安装依赖时需要联网。

## 测试情况

用 6 份 PDF 测过：纯文字（3 页）、带框线表格、扫描件、设计感的简历（照片 + 色条 + 分隔线 + 底色框 + 左右对齐）、3 页合同（长段落 + 首行缩进 + 表格）、双栏排版。转换后的 Word 用 LibreOffice 渲染回图片，和原 PDF 逐页并排对比，见「对比图」文件夹。

**注意**：对比图是用 LibreOffice 打开 Word 文件渲染的，没有在 Microsoft Word 和 WPS 里实测，两者显示可能有细微差别。也还没在真实的 Mac 和 Windows 上跑过启动脚本。
